# مستخرج قطع الموضة

تطبيق بيستخدم جيميناي: ترفع صورة موديل لابسة طقم، فيحلل الصورة ويطلّع قائمة بكل قطعة (لبس، جزم، شنط، إكسسوارات)، تختار القطع اللي عايزها، ويعمل لكل قطعة صورة منتج لوحدها على خلفية استوديو.

- طريقة العرض: مجسّمة (كأنها ملبوسة من غير موديل) أو مفرودة من فوق.
- الخلفية: أبيض أو رمادي فاتح أو بيج.
- المقاس: مربع أو طولي.
- الجودة: عادية (حوالي ٣ ثواني) أو عالية ٢ك (حوالي ١٥ ثانية).
- تحميل كل قطعة لوحدها أو الكل في ملف مضغوط.

مفتاح جيميناي بيفضل على السيرفر بس، ومش بيوصل للمتصفح.

## التشغيل على الجهاز

```bash
npm install
cp .env.example .env   # وحط المفتاح
npm run dev            # http://localhost:3000
```

## متغيرات البيئة

| المتغير | لازم؟ | الافتراضي | الوصف |
|---|---|---|---|
| `GEMINI_API_KEY` | أيوه | | مفتاح جيميناي |
| `GEMINI_MODEL` | لأ | `gemini-3.5-flash` | موديل تحليل الصورة واستخراج قائمة القطع |
| `GEMINI_IMAGE_MODEL` | لأ | `gemini-3.1-flash-lite-image` | موديل صورة المنتج (الجودة العادية) |
| `GEMINI_HQ_IMAGE_MODEL` | لأ | `gemini-3.1-flash-image` | موديل الجودة العالية ٢ك |
| `APP_USERNAME` | لأ | `user` | اسم المستخدم للدخول |
| `APP_PASSWORD` | لأ | فاضي | لو اتحط، التطبيق يفتح صفحة دخول (مدير كلمات السر يقدر يملاها) |
| `SESSION_DAYS` | لأ | `180` | مدة بقاء الدخول على الجهاز بالأيام |
| `SESSION_SECRET` | لأ | فاضي | مفتاح توقيع الجلسة (الافتراضي مشتق من الباسورد) |
| `RATE_LIMIT_PER_MINUTE` | لأ | `30` | أقصى عدد طلبات في الدقيقة لكل جهاز |
| `MAX_IMAGE_MB` | لأ | `12` | أقصى حجم للصورة المرفوعة |
| `MAX_DESCRIPTION_CHARS` | لأ | `3000` | أقصى طول لوصف القطعة |
| `APP_DOMAIN` | لأ | `extract.aaaaaaaaa9000.cloud` | الدومين في إعدادات ترافيك |

## الرفع على السيرفر (بورتينر)

1. في بورتينر: Stacks ← Add stack ← Repository.
2. الاسم: `ai-app-extractor`، الريبو ده، الفرع `refs/heads/main`، الملف `docker-compose.yml`.
3. حط متغيرات البيئة فوق (على الأقل `GEMINI_API_KEY` و`APP_PASSWORD`).
4. فعّل التحديث التلقائي كل 24 ساعة.

التطبيق بيشتغل على بورت 3000 جوه الكونتينر، وترافيك بيوصله بالدومين مع شهادة أمان تلقائية.
فحص الصحة: `GET /api/health`.
